Data Cloud Inspector: privacy policy

Last updated 28 October 2026 (feedback by email, Diagramforce off by default, session-only people data, administrator policy)

Data Cloud Inspector is a browser extension that reads data from the user's own Salesforce org, so that the user can inspect Salesforce Data Cloud: profiles, segments, SQL queries, the data model and its health. It only reads; it never changes data or setup in the org.

What it accesses

  • The Salesforce session already in the browser. The extension uses it to call the org the user is logged in to, as that user. The session is read by the extension's background worker each time it makes a call. It is not stored, and it is sent only to that org.
  • Optionally, an OAuth access token, when the user chooses Log in with OAuth (for an org that blocks browser sessions, or when the user's administrator allows OAuth only). The login happens in the org's own Salesforce login window. The token is kept in the browser's session storage until the browser closes or the user logs out (which also revokes it in Salesforce), and is sent only to that org. A refresh token is never kept.
  • The org's Data Cloud metadata and records, which the extension shows to the user. This can include personal data held in the org, such as names, email addresses and phone numbers.

What it stores

Only in the user's browser:

  • settings (for example the theme);
  • saved SQL queries and the history of queries run (the SQL text, which can contain values the user typed, such as an email address in a filter);
  • the list of orgs the user connected to: each org's domain and ID, the username that connected and a name the user may give it (no session or password);
  • a cache of the org's Data Cloud metadata: object and field names, relationships, mappings, and the result of the Health check (statuses, no records);
  • until the browser closes only: the last Bulk lookup and Compare results, which contain records of people from the org.

No other records or query results are stored. The user can clear everything in the extension's Settings page, or by removing the extension. An administrator can turn off the cache and the query history by policy.

What it sends

  • The extension's only network calls go to the user's own Salesforce org.
  • Open in Diagramforce, off unless the user turns it on in Settings (an administrator can block it), and then only when the user clicks it on a data model or data stream diagram: the diagram's object names, field names and relationships (no records and no session) are handed to diagramforce.com, a free diagram editor run by a third party, which opens in a new tab.
  • Feedback: the extension sends none itself. The Feedback form opens an email in the user's own mail app (or copies the text) with what the user wrote and, if ticked, technical details (extension version, page, the org's domain and API version, and the paths and statuses of recent API calls). The user sends it, or not, from their mail app.

There is no analytics or tracking. Nothing is collected in the background.

Sharing

Data is not sold, and is not shared with third parties, apart from the diagram the user chooses to open in Diagramforce. It is not used for advertising, for creditworthiness or lending, or for any purpose other than the extension's features.

Contact

Questions about this policy: use the contact email on the extension's Chrome Web Store listing, or the extension's Feedback form.

Data Cloud Inspector is an independent tool. It is not made by or affiliated with Salesforce.
