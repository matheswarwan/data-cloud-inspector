Data Cloud Inspector: privacy policy

Last updated 27 October 2026 (Open in Diagramforce added)

Data Cloud Inspector is a browser extension that reads data from the user's own Salesforce org, so that the user can inspect Salesforce Data Cloud: profiles, segments, SQL queries, the data model and its health. It only reads; it never changes data or setup in the org.

What it accesses

  • The Salesforce session already in the browser. The extension uses it to call the org the user is logged in to, as that user. The session is read by the extension's background worker each time it makes a call. It is not stored, and it is sent only to that org.
  • Optionally, an OAuth access token, when the user chooses Log in with OAuth for an org that blocks browser sessions. The login happens in the org's own Salesforce login window. The token is kept in the browser's session storage until the browser closes, and is sent only to that org.
  • The org's Data Cloud metadata and records, which the extension shows to the user. This can include personal data held in the org, such as names, email addresses and phone numbers.

What it stores

Only in the user's browser:

  • settings (for example the theme);
  • saved SQL queries and the history of queries run;
  • the list of orgs the user connected to: each org's domain and ID, the username that connected and a name the user may give it (no session or password);
  • a cache of the org's Data Cloud metadata: object and field names, relationships and mappings.

Records and query results are not stored. The user can clear everything in the extension's Settings page, or by removing the extension.

What it sends

  • Requests for data go to the user's own Salesforce org, and nowhere else.
  • Open in Diagramforce, only when the user clicks it on a data model or data stream diagram: the diagram's object names, field names and relationships (no records and no session) are handed to diagramforce.com, a free diagram editor run by a third party, which opens in a new tab.
  • Feedback, only when the user chooses to send it from the Feedback form: the message, an optional name and email address, an optional screenshot, and optional technical details (extension version, page, the org's domain and API version, and the paths and statuses of recent API calls, never their content). Feedback is sent to the developer's feedback service, hosted on Cloudflare.

There is no analytics or tracking. Nothing is collected in the background.

Sharing

Data is not sold, and is not shared with third parties, apart from the diagram the user chooses to open in Diagramforce. It is not used for advertising, for creditworthiness or lending, or for any purpose other than the extension's features.

Contact

Questions about this policy: use the contact email on the extension's Chrome Web Store listing, or the extension's Feedback form.

Data Cloud Inspector is an independent tool. It is not made by or affiliated with Salesforce.
